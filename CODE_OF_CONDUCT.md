# Code of Conduct

## Our Commitment

Browso is committed to providing a welcoming, inclusive, and respectful environment for all contributors, maintainers, and users. We value collaboration, transparency, and ethical use of AI technology.

This Code of Conduct applies to all spaces managed by the Browso project, including GitHub repositories, issues, discussions, pull requests, and any other community channels.

## Our Standards

### Expected Behavior

We encourage all community members to:

- **Be respectful** — Treat others with courtesy and consideration
- **Be inclusive** — Welcome people of all backgrounds, experiences, and perspectives
- **Be constructive** — Provide helpful feedback and engage in good-faith discussions
- **Be honest** — Share knowledge transparently and acknowledge mistakes
- **Be responsible** — Use Browso ethically and respect privacy and consent
- **Be collaborative** — Help each other learn and grow

### Unacceptable Behavior

The following behaviors are not tolerated:

- **Harassment** — Intimidation, threats, or hostile communication
- **Discrimination** — Treatment based on race, ethnicity, gender, age, religion, disability, sexual orientation, or other protected characteristics
- **Abuse** — Personal attacks, name-calling, or disrespectful language
- **Spam** — Repetitive, unsolicited, or off-topic contributions
- **Malicious use** — Attempting to exploit Browso for unauthorized access, data theft, or harmful automation
- **Privacy violations** — Sharing others' personal information without consent
- **Plagiarism** — Presenting others' work as your own without attribution

## Scope

This Code of Conduct applies to:

- All Browso repository spaces (issues, PRs, discussions, wiki)
- Community channels (Discord, forums, mailing lists)
- In-person events and conferences where Browso is discussed
- Official communications representing the Browso project

This Code of Conduct does not apply to external websites, communities, or organizations not managed by the Browso project.

## Ethical Use

Since Browso is an AI-powered browser automation tool, we ask all users to:

- **Respect website terms of service** — Don't use Browso to violate terms of service or laws
- **Obtain consent** — Get permission before automating actions on behalf of others
- **Avoid scraping harm** — Don't scrape in ways that damage website infrastructure or violate intellectual property
- **Protect privacy** — Don't use Browso to collect personal information without consent
- **Report abuse** — Let maintainers know if you discover misuse of Browso

## Enforcement

### Reporting a Violation

If you witness or experience a violation of this Code of Conduct, please report it by:

1. **Email:** conduct@browso.dev (if available) or contact maintainers directly
2. **GitHub private message:** DM a maintainer via GitHub
3. **Confidential reporting:** Include `[PRIVATE]` in the subject line for sensitive issues

### Investigation and Response

The Browso maintainers will:

- Acknowledge your report within 48 hours
- Investigate the concern fairly and impartially
- Maintain confidentiality to the extent possible
- Determine appropriate action based on severity and context

### Consequences

Violations may result in:

- A private warning and request to modify behavior
- Temporary or permanent removal from community spaces
- Exclusion from contributing to the project
- Public notice of serious misconduct (if appropriate)

The response will be proportionate to the severity of the violation and any previous violations.
